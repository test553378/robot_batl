# テスト報告

## 段階ごとの検証

| 段階 | 検証内容 |
| --- | --- |
| Phase 1 | lint、型検査、Vitest、Viteの本番ビルドを実行。Chromiumでパーツ変更と回転、敵3体のプレビュー、設定の復元を確認。 |
| Phase 2 | lint、型検査、Vitest、Viteの本番ビルドを実行。3武器の第1戦長押し勝利、同じ戦いの再挑戦、2連敗後の補助、全3戦のクリアをシミュレーション。Chromiumで2本指の移動と射撃、ポインター中断、縦横の切替を確認。ソフトウェア描画下で戦闘が遅く進むため、Phase 3で時間処理と描画負荷を調整。 |
| Phase 3 | lint、型検査、Vitest 14件、本番ビルドを確認。Chromiumで第1戦の勝利と次戦への引継ぎ、第2・第3戦の必殺技、全クリアまでを通し試験。WebGL 2がない場合、コンテキストを失った場合、初回のスクリプト取得に失敗した場合の再試行画面を確認。 |

## ブラウザ試験

- Chromium 156（Linux、ソフトウェア描画）で組み立てと保存、2本指の移動・射撃と指の中断、ポーズ、横→縦→横、戦闘、復旧を試験。844 × 390と667 × 320 CSS pxで確認しました。
- Playwright同梱のWebKit 27.2（Linux）でも、組み立てと保存、第1戦の勝利と画面回転、WebGL 2がない場合の案内、コンテキストロスト後の復旧を確認しました。
- 本番ビルドを `/robot_batl/` 配下で読み込み、アセットのHTTPエラーと未処理のJavaScript例外がない状態でプレイできることを確認しました。この確認ではPlaywrightが本番ビルドのファイルを配信しています。

## 戦闘バランス

全武器で移動せずに勝てることを固定ステップで検証しました。第1戦は連射のみ、第2・第3戦は連射に加えてゲージ満タンで必殺技を使用しました。

| 武器 | 第1戦 | 第2戦 | 第3戦 |
| --- | ---: | ---: | ---: |
| ひかりビーム | 15.1秒 | 16.4秒 | 17.7秒 |
| みずジェット | 14.9秒 | 14.3秒 | 19.5秒 |
| ほしロケット | 13.9秒 | 14.2秒 | 20.0秒 |

連射と必殺技を途切れず使う条件では、仕様書の第2・第3戦の時間目標より短くなりました。子どもが実際に遊んだ時間は未計測です。

## 対象と判定の範囲

- Vitestで243通りのモデルを生成し、全スロットのメッシュ、共通ジョイント座標、武器の固定、全体の境界を確認します。すべての角度とモーションでの目視確認は未実施です。
- 参照した画面との違いは [スクリーンショット](screenshots/README.md) に記録しています。
- iPhone実機試験は未実施です。実機のSafariでの表示、OSジェスチャーとマルチタッチ、日本語音声・サイレントモード、戦闘中30 fps以上の目標は未検証です。
- 公開先での検証には、リポジトリ管理者によるPages公開元の設定が必要です。
- 車両への変形、オンライン対戦、完全オフライン再プレイは仕様のP2範囲で、実装していません。
