## 承認画像との比較

味方には車両のグリル、ヘッドライト、タイヤ、回転灯を使い、敵の最後の1体には赤い目、黒と紫の装甲、金の角、背中のマント状装甲を使っています。ゲーム内モデルは面取りした装甲や個別の関節を持つリアルタイム3Dです。参照画像よりパネル数を減らし、塗装とディテールの輪郭を大きくしました。ラスボスのマントは硬質アーマーです。

組み立て画面では横長表示に合わせ、パーツ選択をプレビューの右に配置しました。回転時に車両側面と車輪を見られます。アリーナには明るい青空、都市の遠景、円形の発光ラインを配置しました。参照画像の建物や床の質感、複雑な反射は簡略化しています。
